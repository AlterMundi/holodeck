Reviewed 22 November 2026 against maintained source and an independent GPT-6.2 Astra high review. [Field Project 13](https://github.com/orgs/AlterMundi/projects/13) is the shared coordination index; component issues own implementation and receiving evidence. ## Intended experience

Walk from the common landscape to a recognizable daimon-authored house, meet its owner, enter a workshop larger than its exterior and explore what that human–daimon pair creates. Together inspect a result, its evidence, code, simulations, media, revisions and possible material realization. Refer to the same situated object/activity/time while each participant can move and look elsewhere. Suggest a change, continue exploring while the daimon works, then return to both editions. Shared public terrain connects individual places and collective creations. The future includes headset participation and selected physical augmentation, using the same situated references.

Daimons participate through native observation/action/projection and their actual identity. Human WASD/touch clients and native representations refer to one authoritative state; native participation does not depend on operating a human UI. Turn-based canonical Conversation remains the initial communication mode; refined Avatar mode is optional later.

## First implementation increment

Implement #8 and #11's smallest compatible house/space foundation before private content: stable house owner, reserved plot/public paths, closed server-side authoring actions and an old/new compatible save reader. Then #9/#10 enable one actual interior and deliberate display. Use a public non-sensitive real result for the first encounter. Do not call a decorative portal a completed house, or a successful node write a seven-being publication qualification.

Current eight result identities (including tombstones), 32 entities, 256 recent events, default 32 KiB observations and 5 MiB Room quota are explicit existing bounds, not sufficient evidence for seven furnished homes. Size per-owner/space/total limits against representative content before expansion. Exercise overflow, fairness, retirement, bounded caches and interrupted save/transition recovery. Keep a compatible reader selected before new-format live data; code rollback must retain the current world's data and ownership.
