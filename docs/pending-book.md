# Pendings in Holodeck

The A2UI question mark at the upper left shows the active pending count for the visitor's paired
Conversation. The book reads the same authenticated requests, human tasks and
internal pending pages as Conversation, using its registered same-origin
surface. It does not keep a second ledger, store pending text with world state,
or dismiss a task when the visitor travels. The counter refreshes while its
Holodeck tab is visible. A cross-origin paired surface still needs an explicit
supported reader bridge before this UI can receive that list.

When an existing task really needs work in a specific room, include a named
link such as `https://compaii.dmn.homes/holodeck/?sala=compaii-vestibulo` in the
normal task's links. In the book, selecting the task reads the exact revision.
One valid room destination triggers a jump. If several are attached, the
visitor chooses one. Other tasks remain readable and can be handled from
the Conversation panel inside Holodeck. A title, task topic or free-form instruction
does not identify a room.

The room server verifies current identity, position, access and a reachable
chain of visible doors, then saves the destination once. It uses the final door
in that chain to land the camera and avatar. It does not grant room access,
accept world coordinates from a task, or advance any task state. Existing
active visits and local draft protection still apply.


## Notification language

The first signal is a quiet two-note ascending electronic chirp for new items
that ask for attention. Navegante plays one brief chirp gesture and glances
toward the upper-left mark, whose border lights briefly. Several items
discovered together share one cue. Opening a fresh tab establishes the
current baseline silently; repeat reads and closed items returning with the
same identity do not escalate it. The count remains available after the
accent. Reduced-motion visitors retain the static accent and count.

The existing opt-in World Audio control is in **Ajustes** alongside graphics
and fullscreen. It controls the notification sound as well as the existing
world ambience. The chirp is panned with the companion, uses the same bounded
audio graph and stays silent when audio is muted or the tab is hidden.
